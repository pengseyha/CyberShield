# 🛡️ CyberShield Simulator

CyberShield Simulator is a Bash-based Security Operations Center (SOC) simulation platform developed in Kali Linux for cybersecurity learning and competition presentation.

The project simulates common cyber threats in a safe environment and demonstrates how SOC analysts detect, investigate, and respond to security incidents using professional monitoring workflows.

---

# 🚀 Features

* 🔍 Network Discovery and Host Scanning
* 🎯 Target Selection System
* 🛡️ Port Scanning Detection
* ⚠️ DoS Attack Simulation
* 🔐 Brute Force Login Detection
* ☣️ Malware Detection Simulation
* 📊 SOC Executive Dashboard
* 📈 Severity Classification and Risk Scoring
* 🧠 MITRE ATT&CK Mapping
* 📝 Incident Logging and IOC Export
* 📂 Log Management using `/var/log/cybershield/`
* 🖥️ Professional Terminal-Based UI

---

# ⚠️ Security Notice

CyberShield Simulator is developed for safe educational and defensive cybersecurity learning only.

The project does not perform real harmful attacks, destructive exploitation, or malicious malware execution. All attack modules are controlled simulations created for SOC training and academic demonstration purposes.
